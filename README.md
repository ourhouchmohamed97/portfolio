> 🚀 A modern, high-performance personal portfolio built with Next.js 16, TypeScript, and Tailwind CSS.

## ✨ Features

- ⚡ Static site generation (SSG) for blazing-fast loads
- 🌙 Dark/Light mode with system preference detection
- 📬 Interactive contact modal with email copy + form
- 🧩 Responsive BentoGrid component for showcasing features
- ♿ Accessible, semantic HTML & keyboard navigation
- 🎨 Clean, modern UI with smooth animations

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Icons**: Lucide React + Radix Icons
- **Deployment**: Vercel / Static Export

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/yourusername/mohamed-ourhouch-portfolio.git

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
